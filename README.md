# 14 — Acting | Learning Lab

A standalone, responsive, single-file educational application for GitHub Pages. Part of the numbered Central Hub learning repository collection.

## Learning environment

- **Explore:** overview, discipline cards and progress.
- **Theory Library:** 30 frameworks spanning acting systems, script analysis, movement and voice, improvisation, social performance, psychology, ritual, and ethics. Search, filter, bookmark, and mark studied.
- **Concept Map:** interactive SVG map with discipline filter, zoom and keyboard-selectable nodes.
- **Character Studio:** 11-field character development worksheet with browser-local saving and JSON export.
- **Exercise Studio:** 10 structured practice drills with reflections and completion tracking.
- **Compare:** side-by-side framework analysis.
- **Case Studies:** 5 applied scenarios with revealable multi-theory interpretations.
- **Recall Lab:** 15 retrieval-practice prompts with self-rated review intervals and JSON export.
- **Study Path:** five progressive learning phases.
- **Journal:** six locally saved reflection prompts with JSON export.

## Deployment

In GitHub repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**. The expected address is:

https://obiwandac0-d.github.io/14-Acting/

No dependencies, build system, external APIs, or account are required. Data is stored using browser localStorage; it will not automatically sync between devices. Export JSON before clearing browser data.

## Academic and ethical notes

The app includes introductory reference leads, not an exhaustive verified bibliography or formal systematic evidence grades. Acting practices, philosophical interpretations, sociological theories and empirical cognitive science are distinguished. Training should remain consensual and physically and psychologically safe; no exercise requires traumatic memory recall or coercive emotional exposure.
